# Alexela 95 petrol tracker

Hourly GitHub Action scrapes the Alexela 95 price from https://xydata.ee/kutus/alexela into `data/prices.json`;
`index.html` (GitHub Pages) shows the current price, 7-day low and 30-day chart.

Local: `python3 petrol_tracker.py fetch` / `python3 petrol_tracker.py report`
